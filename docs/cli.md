# Base simple commands

Показать основные команды

```shell
agio --help
```

Простая команда в глобальном окружении

```shell
agio info
```

Простая команда в контексте воркспейса. Если он еще не установлен то установится автоматически

```shell
agio --workspace UUID info
agio -w UUID --help
```

Состав команд может меняться в зависимости от установленных пакетов в воркспейсе.
